<h1 align="center"> Jogo da Cobrinha </h1>

# 🚧 O que é esse projeto?

Uma versão moderna do clássico Jogo da Cobrinha, desenvolvido em Python utilizando a biblioteca Pygame.

# 🎮 Jogabilidade.

- Seta Para Cima / Up: Move a cobra para cima.
- Seta Para Baixo / Down: Move a cobra para baixo.
- Seta Para Esquerda / Left: Move a cobra para a esquerda.
- Seta Para Direita / Right: Move a cobra para a direita
- R: Recomeça a partida (na tela de Game Over)
- Q: Fecha o jogo (na tela de Game Over)
